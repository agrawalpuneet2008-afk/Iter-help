# Iter-help 🎓📍
> **An Intelligent All-in-One University Navigation, Timetable & Faculty Cabin Locator Platform**

Iter-help is a modern, responsive web application engineered to solve fragmented campus life, physical navigation challenges, faculty cabin discovery, and daily academic scheduling at universities.

Built with **React 19**, **Vite**, and **Vanilla CSS** featuring a deep obsidian dark theme with radiant solar orange accents, glassmorphic surfaces, and fluid micro-animations.

---

## 🌟 Key Features

### 1. 🗺️ Interactive Campus Wayfinder (2.5D Map)
- Interactive vector map of academic blocks, libraries, auditoriums, and facilities.
- Floor-level room and cabin positioning with live occupancy radars.
- **Accessibility Routing Mode**: One-click step-free pathfinding prioritizing elevators and ramps.

### 2. 👨‍🏫 Faculty Directory & Cabin Finder
- Search and filter professors by department, academic block, or specific cabin numbers (e.g. `Cabin A-308`, `Cabin C-214`).
- Real-time cabin presence indicators (`In Cabin`, `In Lecture`, `In Lab`).
- **1-Click Cabin Wayfinding**: Directly plot navigation routes from your current location straight to any professor's cabin door.
- Consultation booking and office hour schedules.

### 3. 📅 AI Timetable Scanner & Automated Self-Attendance
- **Screenshot OCR Import**: Upload or paste any timetable image to automatically extract periods, course codes, and classrooms.
- **Daily Self-Attendance Tracker**: Mark attendance with real-time percentage updates.
- **Safe Bunk Calculator**: Instantly computes how many classes you can afford to miss while remaining above the mandatory 75% threshold.
- **Next-Class Live Countdown**: Real-time ticker showing minutes remaining until the next lecture.

### 4. 🪪 Dual-Role Identity & Registration
- **Student Authentication**: Requires student Registration Number, academic department, and front/back ID card photo uploads.
- **Faculty Authentication**: Requires Employee ID, assigned Academic Block, Cabin Number, and front/back ID card photo uploads.
- **Digital Student Pass**: Interactive campus smart ID card with simulated NFC tap and dynamic QR verification.

### 5. 🎨 Design & Aesthetic Excellence
- **Obsidian Dark & Clean Solar Ivory Dual Themes**: Deep obsidian `#030508` with glowing solar orange accents (`#ff6b00`, `#ea580c`).
- **Smooth Animation System**: Staggered card fade-in transitions, soft float effects, and micro-interactions.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/agrawalpuneet2008-afk/Iter-help.git

# Navigate to project folder
cd Iter-help

# Install dependencies
npm install

# Start development server
npm run dev
```

The app will be running at `http://localhost:5173/`.

### Build for Production
```bash
npm run build
```
